# Portket - 주머니 속 포트폴리오

## 소개

이 프로젝트는 2022년에 처음 기획되어 2024년에 마무리되었습니다. 투자를 하면서 가장 어렵고 불편했던 점을 해결하고자 시작했습니다. 여러 증권사와 계좌에 분산된 투자 정보를 한눈에 파악하기 어려웠고, 각각의 보유 비중을 기억하고 확인하는 것이 쉽지 않았습니다. 개인이 기억하기 어려운 규모의 포트폴리오가 문제가 된다면 그것도 의미있겠지만, 무엇보다 이런 소재로 처음부터 끝까지 프로젝트를 완성해보고 싶었습니다.

기획을 품고 있던 중 갑작스럽게 Java 백엔드 개발자로 일하게 되었습니다. 학교에 다니면서, 일을 하면서 공부가 얼마나 어렵고 외로운 일인지 실감했습니다. 그래서 이 프로젝트가 제 공부의 결과물이자, 학생들에게 뼈대가 되어 도움이 되었으면 하는 마음으로 진행했습니다. 그런 관점에서 일부 오버 엔지니어링된 부분도 있습니다.

2024년, 여러 프레임워크와 설계 변경을 거쳐 프로젝트를 마무리했습니다. 격변하는 시대 속에 AI가 막 사용되기 시작하던 때라 대단히 도움을 받았습니다. 현재 이 글을 작성하는 2026년 1월 기준으로는 저도 업무 내외에 코딩 에이전트를 사용하고 있지만, 당시에는 이런 기술이 존재하는지, 어떻게 사용하는지, 어떻게 동작하는지를 물어볼 수 있었습니다. 마치 한 달에 100만원쯤 하는 과외선생님을 2만원에 만난 기분이었습니다. 이때 저는 꽤 높은 뎁스의 성장을 이루었던 것 같습니다.

하루 빨리 공개해서 지치고 힘든 학생들에게 도움이 되고 싶었지만, 이미 시간이 지나 이제 "어떻게 구현하는가"는 그다지 의미 있는 질문이 아닌 듯합니다. (AI 에이전트의 효과에 대한 이야기이니 오해 없으시길 바랍니다.) 다른 일을 하기 위해 이 일을 마무리하려고 합니다. 감사합니다.

## 주요 기능

- 다중 포트폴리오 통합 관리
- 보유 자산 비중 확인
- 거래 기록 관리

## 기술 스택

Spring Boot | JOOQ | PostgreSQL | OAuth2 + JWT | Docker

## 향후 계획

- 지속적으로 업데이트 예정
